monaco-wasm

The Monaco editor for Rust web apps. Add a Cargo dependency and get the editor, its workers, and JSON diagnostics. No npm, no CDN, no worker setup.

Source on GitHub

Yew

A MonacoEditor component for Yew 0.23.

[dependencies]
yew = { version = "0.23", features = ["csr"] }
monaco-yew = "0.1"
html! {
    <MonacoEditor
        language="json"
        initial_value="{}"
    />
}

Leptos

A MonacoEditor component for Leptos 0.8, with CSR, SSR, and hydration.

[dependencies]
leptos = { version = "0.8", features = ["csr"] }
monaco-leptos = { version = "0.1", features = ["csr"] }
view! {
    <MonacoEditor
        language="json"
        initial_value="{}"
    />
}
Open the Leptos quickstart

What you get

  • Bundled runtime. Monaco 0.57 with the editor and JSON workers ships inside the crate and reaches your build through wasm-bindgen. Languages: JSON with validation, YAML, and plain text.
  • The editor owns the text. Read or replace it through a handle when you need it; change events carry a version, not the document.
  • Reactive settings. Language, theme, and editor options update the existing editor in place.
  • Server rendering. The Leptos component renders an empty host on the server and creates the editor after hydration.
  • Plain Rust/WASM too. monaco-wasm is the framework-free core both components build on.
  • Strict CSP works with worker-src blob:, style-src 'unsafe-inline', and font-src data:.

Each quickstart is a complete Trunk project you can copy as the start of your own app.
